### Property-Based Invariant Tests (`fast-check`)
1. **Allowance Non-Negativity**: For any combination of positive or negative balance, upcoming obligations, and goal reserves across all 30 days, `dailyAllowance` is strictly $\ge 0$ paise.
2. **Deep Immutability**: Passing an `Object.freeze` protected state to `simulateDecision` produces exact before/after metrics without modifying a single property of the input state.
3. **Monotonic Risk**: Risk level degrades monotonically as forecast margin shrinks.
4. **Subscription Invariance**: Cancelling an active subscription never decreases the daily allowance.
5. **Deterministic RNG**: `mulberry32` produces identical random sequence for identical seeds.
